# Photos des tableaux

Dossier de travail pour préparer les photos des œuvres avant leur ajout au site.

- `a-traiter/` : déposer ici les photos brutes (JPEG, PNG, HEIC…), telles qu'elles
  sortent de l'appareil ou du téléphone.
- `traitees/` : photos retravaillées (recadrées, redressées, luminosité harmonisée),
  prêtes à être importées depuis le back-office (`/admin`).

Les images elles-mêmes ne sont pas versionnées dans git (seuls ce fichier et la
structure des dossiers le sont).
